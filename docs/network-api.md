# 🌐 Network API

The Network API provides methods to interact with and monitor the peer-to-peer network of the Hybrid Blockchain. It includes operations for checking node status, peer information, network statistics, and synchronization status.

## 📚 Available Methods

- [👥 Get Peer Info](network_api/GetPeerInfo.md)
- [📊 Get Network Stats](network_api/GetNetworkStats.md)
- [➕ Add Peer](network_api/AddPeer.md)
- [📡 Get Node Status](network_api/GetNodeStatus.md)
- [🔄 Sync Status](network_api/GetSyncStatus.md)
- [🔢 Get Protocol Version](network_api/GetProtocolVersion.md)
- [⚡ Get Node Performance](network_api/GetNodePerformance.md)
- [🚪 Get Bootnode Info](network_api/GetBootnodeInfo.md)
- [⏱️ Get Peer Latency](network_api/GetPeerLatency.md)
- [📶 Get Bandwidth Usage](network_api/GetBandwidthUsage.md)
- [📈 Get Network Growth](network_api/GetNetworkGrowth.md)
- [👤 Get Active Addresses](network_api/GetActiveAddresses.md)
- [🔢 Get Peer Count](network_api/GetPeerCount.md)
- [⚠️ Get Slashing Events](network_api/GetSlashingEvents.md)
- [⏰ Get Validator Uptime](network_api/GetValidatorUptime.md)
- [📊 Get Daily Transaction Volume](network_api/GetDailyTransactionVolume.md)

These methods are essential for monitoring network health, diagnosing connectivity issues, and understanding the overall state of the blockchain network infrastructure.
