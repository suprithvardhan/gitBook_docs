# 🔗 Blockchain API

The Blockchain API provides methods to query and interact with the core blockchain data structures and state. It includes operations for retrieving blocks, querying chain information, analyzing network statistics, and validating addresses.

- [💰 Get Rich List](blockchain_api/GetRichList.md)
- [📈 Get Blockchain Stats](blockchain_api/GetBlockchainStats.md)
