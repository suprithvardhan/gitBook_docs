# 💸 Transaction API

The Transaction API provides methods for creating, sending, and analyzing transactions on the Hybrid Blockchain network. It includes operations for checking balances, managing UTXOs, estimating fees, and querying transaction history.

## 📚 Available Methods

- [💰 Get Balance](transaction_api/GetBalance.md)
- [🔍 Get UTXOs](transaction_api/GetUTXOs.md)
- [📊 Get Account State](transaction_api/GetAccountState.md)
- [📝 Create Unsigned Transaction](transaction_api/CreateUnsignedTransaction.md) (also accessible as createTransaction)
- [📤 Send Transaction](transaction_api/SendTransaction.md)
- [🔎 Get Transaction](transaction_api/GetTransaction.md)
- [⏳ Get Pending Transactions](transaction_api/GetPendingTransactions.md)
- [💵 Estimate Fee](transaction_api/EstimateFee.md)
- [📜 Get Transaction History](transaction_api/GetTransactionHistory.md)
- [🔐 Get Transaction Proof](transaction_api/GetTransactionProof.md)
- [🔄 Decode Transaction](transaction_api/DecodeTransaction.md)
- [🐛 Debug Transaction](transaction_api/DebugTransaction.md)
- [📖 Call Read Only](transaction_api/CallReadOnly.md)
- [⚡ Get Recent Transactions](transaction_api/GetRecentTransactions.md)
- [🧠 Get Mempool Info](transaction_api/GetMempoolInfo.md)
- [📈 Get Average Fees](transaction_api/GetAverageFees.md)
- [🔍 Trace Block](transaction_api/TraceBlock.md)
- [🔍 Search By Address](transaction_api/SearchByAddress.md)

These methods are essential for building applications that send and receive value on the Hybrid Blockchain network, providing detailed insights into transaction status, history, and performance.
