# 👛 Wallet API

The Wallet API provides methods to create and manage wallets on the Hybrid Blockchain network. It includes operations for generating wallets, importing existing ones, retrieving information, signing messages, and more.

## 📚 Available Methods

- [🆕 Create Wallet](wallet_api/CreateWallet.md)
- [📥 Import Wallet](wallet_api/ImportWallet.md)
- [📄 Get Wallet Info](wallet_api/GetWalletInfo.md)
- [🌐 Create HD Wallet](wallet_api/CreateHDWallet.md)
- [📋 Get Addresses](wallet_api/GetAddresses.md)
- [👥 Create Multi-Signature Wallet](wallet_api/CreateMultiSigWallet.md)
- [✍️ Sign Message](wallet_api/SignMessage.md)
- [✅ Verify Signature](wallet_api/VerifySignature.md)

These methods are crucial for users and developers to interact with the blockchain securely through their wallets. Wallet operations enable secure key management, transaction signing, and identity verification on the Hybrid Blockchain network.
