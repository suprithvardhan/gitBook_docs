# GetBlockCount

**Category:** Blockchain  
**Method:** `getBlockCount`

---

## 🧾 Description

Returns the current height/number of blocks in the blockchain.

---

## 📥 Parameters

None

---

## 📡 Request

```json
{
  "jsonrpc": "2.0",
  "method": "getBlockCount",
  "params": {},
  "id": 1
}
```

## 📤 Returns

Returns the current block height as an integer.

```json
1600
```
