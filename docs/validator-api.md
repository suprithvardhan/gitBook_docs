# 🏆 Validator API

The Validator API provides methods to interact with and monitor the validator network of the Hybrid Blockchain. It includes operations for staking tokens, checking validator status, managing rewards, and analyzing validator performance.

## 📚 Available Methods

- [👥 Get Validators](validator_api/GetValidators.md)
- [💼 Get Stake Info](validator_api/GetStakeInfo.md)
- [💰 Stake Tokens](validator_api/StakeTokens.md)
- [🔄 Unstake Tokens](validator_api/UnstakeTokens.md)
- [💸 Get Validator Rewards](validator_api/GetValidatorRewards.md)
- [📊 Get Validator Performance](validator_api/GetValidatorPerformance.md)
- [✅ Verify Validator](validator_api/VerifyValidator.md)
- [🏅 Get Top Validators](validator_api/GetTopValidators.md)
- [📈 Get Total Staked](validator_api/GetTotalStaked.md)
- [📝 Get Validator Stats](validator_api/GetValidatorStats.md)
- [📆 Get Daily Validator Rewards](validator_api/GetDailyValidatorRewards.md)

These methods are crucial for participating in the consensus mechanism of the Hybrid Blockchain network, enabling users to become validators, stake tokens, and earn rewards while helping secure the network.
